\noindent
\textbf{Problem Statement}

\vspace{0.3cm}

\noindent
Haskell Language Server (HLS) currently supports \textit{Goto Definition} only for
functions defined within a user’s project. This project extends the feature to
external dependencies, allowing developers to navigate directly to the
implementation of library functions from their IDE. By indexing \texttt{.hie}
files generated by GHC using tools such as \texttt{hiedb}, HLS can locate and
open source definitions from third-party libraries.
